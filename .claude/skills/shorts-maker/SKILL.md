# 실화 쇼츠 제작 스킬

도구: `tools/shorts/` (commons.py 소재 검색·다운로드, tts.py 내레이션, render.py 렌더·검수)
예시 프로젝트: `videos/2026-11-19_젠슨황/` (script.json 형식은 여기를 그대로 따라 한다)

## 진행 순서 (반드시 이 순서)

1. **주제·각도 정하기** — 사용자가 인물만 말하면 "반전 있는 인생 한 줄"을 제안한다
   (예: 화장실 청소부 → 세계 1위 회사). 분석 채널에서 잘 된 공식: 도입에 반전 요약,
   중간에 위기, 끝에 명언·질문.
2. **사실 확인** — WebSearch로 핵심 사실(연도·숫자·인용)을 2개 이상 출처로 확인. 출처 URL을 메모.
3. **대본 먼저 보여주기** — 13문장 안팎, 1.1배속 기준 55~70초. 표(번호/내레이션/자막/화면)로
   보여주고 **사용자 확인을 받은 뒤** 다음 단계로 간다. 사용자가 "바로 만들어"라고 하면 생략.
4. **소재 찾기** — `python3 tools/shorts/commons.py search "인물 영문명"` 와 `search --video "인물 영문명"`.
   실제 영상 클립을 2~4개 장면에 넣는다(인물이 말하는 장면, 제품·장소 B-roll).
   받기: `python3 tools/shorts/commons.py get <프로젝트> <키> "<파일 제목>"`
5. **TTS** — `python3 tools/shorts/tts.py <프로젝트>`
6. **미리보기 검수** — `python3 tools/shorts/render.py <프로젝트> --preview` → out/preview.jpg 를 직접 보고
   아래 검수표 확인 후 수정.
7. **본 렌더** — `python3 tools/shorts/render.py <프로젝트>` (약 3분). 결과·검수 수치를 보고하고
   영상·설명란·자막을 SendUserFile 로 보낸다.
8. **저장** — 프로젝트 폴더를 커밋·푸시 (media/·tts/·out/*.wav 는 .gitignore 로 제외됨).

## 절대 규칙

- **방송사·유튜버·영화 등 남의 영상은 쓰지 않는다.** 소재는 Public domain, CC0, CC BY, CC BY-SA,
  공공누리 1유형만. NC(비영리), ND(변경금지)는 사용 금지.
- 사실이 아닌 내용(불륜·사망·스파이 같은 지어낸 이야기)을 만들지 않는다. 확인 안 된 내용은 빼거나 "~라고 알려져 있다".
- 사진 속 인물·시기가 내레이션과 맞아야 한다. 맞는 사진이 없으면 `card` 장면(큰 숫자/연도)으로 대체.
- 설명란에 모든 소재의 작성자·라이선스·링크와 참고 기사 출처를 적는다(렌더러가 media.json 으로 자동 채움).

## 검수표 (미리보기·완성본 모두)

- [ ] 도입: 첫 3초 안에 반전 요약 + 인물 얼굴(가능하면 실제 영상)
- [ ] 흐름: 같은 말 반복 없음, 한 장면 6초 이하
- [ ] 화면: 사진·영상이 내레이션과 맞음, 자막이 화면 밖으로 안 나감, 얼굴이 제목에 안 가림
- [ ] 소리: 평균 음량 -16 ~ -13 dB, 배경음이 말을 덮지 않음
- [ ] 출처: 모든 장면 오른쪽 아래 출처 표기, 설명란 출처 완비

## 환경 메모 (클라우드 세션)

- 필요 네트워크: commons.wikimedia.org, upload.wikimedia.org, speech.platform.bing.com
- 필요 설치: `pip install edge-tts`, `apt-get install -y fonts-nanum`
- Commons API는 429를 자주 낸다 → 잠시 기다렸다 재시도. 파일 자체는 경로를 계산해 받으므로 대개 된다.
- 기본 음성: ko-KR-HyunsuMultilingualNeural, rate +16%, pitch -4Hz, 최종 1.1배속 (script.json 에서 변경)
