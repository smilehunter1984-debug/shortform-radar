# 쇼츠 제작 폴더

영상 하나당 폴더 하나: `videos/날짜_주제/`

| 파일 | 내용 |
|---|---|
| `script.json` | 제목, 음성 설정, 배속, 장면별 내레이션·자막·화면 |
| `media.json` | 사용한 사진·영상의 출처·라이선스 (설명란 출처 자동 생성용) |
| `설명란_초안.txt` | 유튜브 제목 후보·설명·참고 자료 (`{CREDITS}` 자리에 출처가 들어감) |
| `out/*.mp4` | 완성 영상 (1.1배속) |
| `out/*.srt` | 자막 파일 |
| `out/유튜브_설명란.txt` | 출처까지 채워진 최종 설명란 |
| `out/preview.jpg` | 장면별 미리보기 |

`media/`(원본 사진·영상)와 `tts/`(음성 조각)는 용량 때문에 저장소에 올리지 않습니다.
`media.json` 에 원본 링크가 있으므로 `tools/shorts/commons.py get` 으로 다시 받을 수 있습니다.

새 영상 만들기: Claude Code에서 "○○ 쇼츠 만들어줘" → `shorts-maker` 스킬이 순서대로 진행합니다.
