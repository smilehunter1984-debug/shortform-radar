# 숏폼레이더

유튜브 숏폼 트렌드 분석 웹페이지입니다. `index.html` 하나로 동작하며, 브라우저에서 바로 열면 됩니다.

## 페이지
- **영상 분석** — 일자·카테고리별 급상승 상위 영상, 인기 업로드 시간 그래프, 인기 키워드, 카테고리 점유율
- **급상승 영상** — 급상승/조회수/좋아요/댓글/업로드 순 정렬
- **급상승 채널** — 최근 7·5·3일/오늘 기준 채널 순위, 구독자 대비 조회수
- **채널·영상 검색** — 고급 필터(알고리즘 스코어, 조회수 구간, 영상 타입, AI 영상, 제외 키워드)
- **랭킹** — 일간/주간 채널·영상 순위

## 데이터
- 기본은 임의로 생성한 **데모 데이터**입니다.
- 우측 상단 **데이터 설정**에 YouTube Data API v3 키를 넣으면 한국(KR) 인기 영상 차트를 불러와 분석합니다. 키는 브라우저 localStorage에만 저장됩니다.

## 지표
- **급상승 수치**: 업로드 후 시간당 조회수를 하루 기준으로 환산하고 좋아요·댓글 참여도로 가중한 값
- **알고리즘 스코어**: 전체 영상의 급상승 수치 분위를 5단계로 나눈 값
