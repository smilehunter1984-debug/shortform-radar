# 견적 요청 받기 설정 (구글, 무료, 약 10분)

견적 페이지(`quote/index.html`)에서 고객이 보낸 내용과 사진을
**Gmail 알림 + 구글 시트 명단 + 구글 드라이브 사진 폴더**로 받는 설정입니다.
PC에서 하시는 게 편합니다.

## 1. 스크립트 만들기
1. 구글에 로그인한 브라우저에서 https://script.google.com 열기 → **새 프로젝트**
2. 왼쪽 위 '제목 없는 프로젝트'를 **콤마 견적 접수**로 바꾸기
3. 편집기에 있는 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 복사해 붙여넣기 → 저장(💾)

## 2. 권한 허용 (처음 한 번)
1. 위쪽 함수 선택칸에서 **setup** 고르고 **실행**
2. '권한 검토' → 내 구글 계정 선택
3. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → 콤마 견적 접수(으)로 이동(안전하지 않음)** → **허용**
   - 사장님이 직접 만든 스크립트라서 나오는 경고입니다.
4. 아래 실행 로그에 '준비 완료'가 나오면 끝. 구글 드라이브에 **콤마 견적요청 명단** 시트가 생깁니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정
   - 다음 사용자 인증정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사

## 4. 견적 페이지에 연결
복사한 주소를 Claude에게 보내 주세요. `quote/index.html` 의 `endpoint` 에 넣어 드립니다.

## 알아두기
- 견적이 들어오면 **Gmail로 알림 메일**(사진 첨부)이 옵니다. 폰 Gmail 앱 알림을 켜 두세요.
- 명단 시트의 '상태' 칸에 `신규 → 견적발송 → 계약 → 시공완료` 처럼 적어 관리하면 됩니다.
- 스크립트를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 해야 반영됩니다(주소는 그대로).
- 고객 개인정보가 담기므로 시트·폴더는 공유하지 마세요.
