# 콤마 콜백문자 앱 (현재 1.2)

통화가 끝나면 자동으로 안내 문자를 보내는 갤럭시 전용 개인 앱입니다. 기존 '오토메세지'를 대신합니다.

## 최신 버전 받기 (고정 주소)
**https://github.com/smilehunter1984-debug/shortform-radar/releases/download/callback-app-latest/comma-callback.apk**

폰에서 누르면 바로 받아지고, 기존 앱 위에 덮어 설치하면 설정·이력이 그대로 남습니다.
앱을 고치면 이 주소의 파일이 자동으로 새 버전으로 바뀝니다.

## 들어있는 기능
1. 통화 종료 감지 → 받은 전화 / 부재중(거절 포함) / 건 전화 구분 (기본: 받은 전화·부재중만 발송)
2. 연락처에 저장된 번호 제외, 수신거부 번호 목록, 휴대폰 번호(010 등)에만 발송
3. 같은 번호는 정한 일수(기본 30일) 안에 다시 안 보냄
4. 하루 최대 발송 수(기본 100건)
5. 요일·시간대 설정, 자동 발송 켜기/끄기, **밤 9시~아침 8시는 무조건 안 보냄**
6. 문자 내용 앱에서 수정. 80바이트를 넘으면 장문(LMS)으로 보내고, 장문이 실패하면 짧은 문자로 나눠 다시 보냄
7. 장문 제목(기본 '콤마인테리어필름') – 받는 폰에 '[제목없음]' 대신 표시 (1.1)
8. 사진 첨부 최대 3장 → 사진문자(MMS), 실패하면 글자만 다시 보냄 (1.2)
9. 발송 이력: 번호·시각·통화종류·성공/실패 이유, 안 보낸 이유까지
10. 상단 상주 알림 + 메인 화면 '마지막 통화 감지 시각'
11. 첫 실행 때 권한·'제한된 설정 허용'·배터리 설정 단계별 안내, 테스트 발송 버튼
12. **시험 모드**: 켜져 있으면 시험용 번호에서 온 전화에만 발송(기존 앱과 겹치지 않게)

## 실제 폰에서 확인된 것 (2026-11-25~26, 갤럭시)
- 통화 감지·번호 확인·받은 전화/부재중/건 전화 구분, 밤새 앱 유지(삼성 절전에 안 꺼짐)
- 장문(LMS) 발송·도착 – 갤럭시, 아이폰 모두 정상, 제목 정상 표시
- 야간 차단, 시험 모드 차단, 건 전화 미발송
- 아직: 사진문자(1.2)는 실제 폰 시험 전

## 운영 시작하기 (오토메세지에서 넘어가기)
1. ② 문자 내용·발송 규칙 → **보낼 문자**를 최종 문구로 (견적 페이지 주소가 생기면 넣기)
2. 사진을 넣을 거면 ② → 첨부 사진 고르기 → 아내분 폰으로 **테스트 발송**해서 사진 도착 확인
3. **오토메세지 끄기** (둘 다 켜져 있으면 고객이 두 번 받음)
4. ② → **시험 모드 끄기** → 이때부터 고객에게 발송
5. 1~2주 동안 하루 한 번 **발송 이력** 확인 → 문제없으면 오토메세지 해지

## 주의
- 할인·이벤트 같은 홍보 문구를 넣으면 '광고문자'가 됩니다: 맨 앞 (광고), 업체명, 무료 수신거부 방법을 넣어야 합니다.
- 원UI 큰 업데이트 후에는 앱의 ① 설정 안내를 열어 ✅가 그대로인지 확인하세요.
- 사진문자·장문은 모바일 데이터가 켜져 있어야 나갑니다.

## 나중에 추가할 수 있는 것
상황별 다른 문구, 통화 후 메모, 구글 시트 연동, 시공완료 고객 예약발송(리뷰요청·관리안내), 통계, 듀얼심 회선 선택, 야간 통화의 다음날 아침 발송
