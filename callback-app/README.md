# 콤마 콜백문자 앱 (1단계)

통화가 끝나면 자동으로 안내 문자를 보내는 갤럭시 전용 개인 앱입니다.

## 들어있는 기능
1. 통화 종료 감지 → 받은 전화 / 부재중(거절 포함) / 건 전화 구분 (처음엔 받은 전화·부재중만 발송)
2. 연락처에 저장된 번호 제외
3. 같은 번호는 정한 일수(기본 30일) 안에 다시 안 보냄
4. 하루 최대 발송 수(기본 100건)
5. 요일·시간대 설정, 자동 발송 켜기/끄기 스위치, **밤 9시~아침 8시는 무조건 안 보냄**
6. 문자 내용 앱에서 수정. 80바이트 넘으면 장문(LMS)으로, 장문이 실패하면 짧은 문자로 나눠 재발송
7. 발송 이력(번호·시각·통화종류·성공/실패와 이유, 안 보낸 이유까지)
8. 상단 상주 알림 + 메인 화면 '마지막 통화 감지 시각'
9. 첫 실행 시 권한·'제한된 설정 허용'·배터리 설정 단계별 안내
10. 테스트 발송 버튼
- 사진 첨부(1.2): ② 설정에서 최대 3장 선택 → 사진문자(MMS)로 발송, 실패하면 글자만 재발송
- 추가: 수신거부 번호 목록, 휴대폰 번호(010 등)에만 발송, **시험 모드**(처음엔 켜져 있음: 시험용 번호에서 온 전화에만 발송)

## 폰에 설치하는 법
1. GitHub 저장소 → **Actions** 탭 → '콜백문자 앱 빌드' 최신 실행(초록 체크) → 맨 아래 **comma-callback-apk** 내려받기
2. 받은 zip 파일을 '내 파일' 앱에서 열어 압축 풀기 → `comma-callback.apk` 누르기
3. 설치가 막히면: 설정 → 보안 및 개인정보 보호 → **보안 위험 자동 차단 끄기**, '내 파일'에 '출처를 알 수 없는 앱 설치' 허용 (설치 후 자동 차단은 다시 켜도 됨)
4. 앱을 열면 나오는 **설정 안내** 1~5번을 순서대로
5. ②에서 시험용 번호(가족 폰) 입력 → 메인에서 '자동 발송 켜기' → 가족 폰으로 전화해서 시험
6. 2주간 이력으로 확인되면 ②에서 시험 모드 끄기 → 기존 콜백앱 해지

업데이트는 같은 방법으로 새 APK를 설치하면 덮어써집니다(설정·이력 유지).

## 꼭 시험할 것
- 부재중 / 받고 끊기 / 내가 건 전화 / 10초 미만 통화
- **장문(LMS)**: 모바일 데이터를 켠 상태에서. 실패하면 이력에 이유와 코드가 남습니다.
- 재부팅 후 상단 알림이 다시 뜨는지 (안 뜨면 앱을 한 번 열어주면 됨)

## 아직 없는 것 (2단계)
상황별 다른 문구, 통화 후 메모, 구글 시트 연동, 시공완료 예약발송, 통계, 듀얼심 회선 선택, 야간 통화의 다음날 아침 예약발송
